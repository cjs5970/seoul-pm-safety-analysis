# Data Directory (데이터 보관소)

이 폴더는 [서울시 공유 자전거 및 PM 안전 규제 영향 분석] 프로젝트에 사용된 **모든 수집 데이터 원본**과 이를 분석에 적합한 형태로 가공한 **전처리 파이프라인 및 결과물**을 관리하는 공간입니다.

## 디렉터리 구성 및 설명

### 1. `original-datasets/` (원본 데이터셋)
교통사고 분석 시스템(TAAS)과 서울시 열린데이터광장(Open Data Plaza) API 등을 통해 수집한 5종류의 공공데이터 원본 파일(`.csv`, `.xlsx`)이 위치해 있습니다.

* **주요 수집 데이터**
  * 연도별/월별 TAAS PM 및 자전거 교통사고 현황
  * 서울시 자치구별 코로나19 확진자 현황
  * 공공자전거(따릉이) 이용 정보 및 대여소 현황
  * 개인형 이동장치(PM) 주정차 위반 견인 현황 등

### 2. `data-preprocessing/` (데이터 전처리)
다양한 형태로 산재해 있는 원본 데이터를 분석(EDA) 및 통계 검증에 바로 사용할 수 있도록 정제한 Jupyter Notebook(`.ipynb`) 파일들과, 그 결과로 도출된 **최종 병합 데이터셋**이 포함되어 있습니다.

* **주요 전처리 파이프라인:**
  * 결측치(NaN) 처리 및 비정상적인 분포를 띠는 이상치(Outlier) 정제
  * 다수의 연도별/월별 파일로 분할된 데이터 통합 (Concat/Merge)
  * 서로 다른 데이터셋 간 병합 시 발생하는 문자열(String)과 날짜형(Datetime) 데이터의 타입 충돌 교정 및 시계열 기준선 통일
