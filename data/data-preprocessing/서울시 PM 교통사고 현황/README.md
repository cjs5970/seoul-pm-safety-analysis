# 서울시 PM 교통사고 데이터 전처리 방식

이 폴더는 `data/original-datasets/교통사고 분석 시스템(TAAS)/2019.xlsx` ~ `2024.xlsx`에 있는 PM 교통사고 데이터를 팀원 전처리 폴더의 CSV 양식에 맞춰 정리한 결과다.

팀원 데이터와 맞추기 위해 공통 키를 다음처럼 통일했다.

| 구분 | 사용 컬럼 | 형식 |
|---|---|---|
| 지역 | `자치구` | `강남구`, `송파구` 등 서울시 25개 자치구 |
| 월 | `연월` | `YYYY-MM` |
| 연도 | `연도` | 정수형 연도 |

## 원본 데이터

사용한 원본 파일은 다음과 같다.

```text
data/original-datasets/교통사고 분석 시스템(TAAS)/2019.xlsx
data/original-datasets/교통사고 분석 시스템(TAAS)/2020.xlsx
data/original-datasets/교통사고 분석 시스템(TAAS)/2021.xlsx
data/original-datasets/교통사고 분석 시스템(TAAS)/2022.xlsx
data/original-datasets/교통사고 분석 시스템(TAAS)/2023.xlsx
data/original-datasets/교통사고 분석 시스템(TAAS)/2024.xlsx
```

각 파일은 연도별 PM 교통사고 자료이며, 원본에 빈 행이 많이 포함되어 있어 전처리 첫 단계에서 완전히 비어 있는 행을 제거했다.

## 규제 기준 제외

PM 규제 기준일은 아직 확정하지 않았으므로 이번 전처리에서는 규제 관련 컬럼을 만들지 않았다.

제외한 항목:

```text
규제기준일
규제구분
규제전후 비교 파일
```

나중에 규제 기준일이 확정되면 `연월` 컬럼을 기준으로 `규제전`, `경계월`, `규제후` 같은 파생변수를 추가하면 된다.

## 전처리 과정

1. 연도별 엑셀 파일을 모두 읽는다.
2. 완전히 비어 있는 행을 제거한다.
3. `발생년월` 값을 `연월`, `연도`, `월`로 분리한다.
4. `시군구`에서 서울시 자치구명을 추출해 `자치구` 컬럼을 만든다.
5. 사망자수, 중상자수, 경상자수, 부상신고자수를 숫자형으로 변환한다.
6. 피해 규모 파생변수를 만든다.
7. PM이 가해자인지 피해자인지 구분한다.
8. 사고유형과 도로형태를 대분류/소분류로 분리한다.
9. 사고 단위, 월별, 연도별 파일을 각각 저장한다.

## 주요 파생 변수

| 컬럼 | 계산 방식 |
|---|---|
| `총부상자수` | `중상자수 + 경상자수 + 부상신고자수` |
| `총사상자수` | `사망자수 + 총부상자수` |
| `중상이상자수` | `사망자수 + 중상자수` |
| `PM_가해여부` | 가해운전자 차종이 `개인형이동수단(PM)`이면 `Y`, 아니면 `N` |
| `PM_피해여부` | 피해운전자 차종이 `개인형이동수단(PM)`이면 `Y`, 아니면 `N` |
| `PM_역할` | `가해`, `피해`, `가해+피해`, `기타` |
| `사고유형_대분류` | `사고유형`에서 ` - ` 앞부분 |
| `사고유형_소분류` | `사고유형`에서 ` - ` 뒷부분 |
| `도로형태_대분류` | `도로형태`에서 ` - ` 앞부분 |
| `도로형태_소분류` | `도로형태`에서 ` - ` 뒷부분 |

## 파일별 용도

### `서울시_PM_교통사고_사고단위.csv`

사고 1건이 한 행인 가장 상세한 파일이다. 사고유형, 법규위반, 가해/피해 운전자 특성, 사상자 수 등을 분석할 때 사용한다.

추천 분석:

```text
법규위반별 사고 분포
사고유형별 사고 분포
가해운전자 연령대 분석
PM이 가해자인 사고와 피해자인 사고 비교
```

### `서울시_자치구별_월별_PM교통사고.csv`

팀원 데이터의 `연월`, `자치구` 기준과 맞춰 만든 월별 패널이다. 사고가 없는 자치구-월도 `PM_사고건수 = 0`으로 포함했다.

추천 분석:

```text
월별 PM 사고 추세
자치구별 PM 사고 변화
코로나, 견인, 주차구역 등 다른 월별 데이터와 결합
```

### `서울시_자치구별_연도별_PM교통사고.csv`

월별 파일을 연도 단위로 집계한 파일이다.

추천 분석:

```text
연도별 사고 증가/감소 비교
자치구별 연간 사고 순위
보고서용 연도별 요약 표 작성
```

## 결측 및 예외 처리

- 2024년 원본에는 `구분번호` 컬럼이 없다. 그래서 `PM-연도-일련번호` 형식으로 `사고ID`를 새로 만들었다.
- `사망자수`, `중상자수`, `경상자수`, `부상신고자수`가 비어 있으면 `0`으로 처리했다.
- 자치구는 `시군구` 문자열에서 서울시 25개 자치구명을 찾아 추출했다.
- 월별 패널은 모든 자치구와 모든 월을 포함하도록 만들었기 때문에 사고가 없는 월도 행이 존재한다.
- 규제 기준일은 아직 지정하지 않았으므로 규제 관련 컬럼과 비교 파일은 생성하지 않았다.

## 검증 결과

전처리 후 행 수와 집계 합계를 확인했다.

| 검증 항목 | 결과 |
|---|---:|
| 사고단위 행 수 | 3,346 |
| 월별 `PM_사고건수` 합계 | 3,346 |
| 연도별 `PM_사고건수` 합계 | 3,346 |
| 월별 패널 기간 | 2019-01 ~ 2024-12 |
| 월별 패널 자치구 수 | 25 |

즉, 사고단위 데이터의 전체 사고 수와 월별/연도별 집계 사고 수가 일치한다.
