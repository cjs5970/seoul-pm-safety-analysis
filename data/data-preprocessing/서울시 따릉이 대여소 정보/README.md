# 서울시 공공자전거(따릉이) 대여소 마스터 DB 전처리

## 1. 데이터 개요
* **데이터명:** 서울시 공공자전거(따릉이) 기간별 대여소 현황 정보 통합본
* **기간:** 2021년 1월 ~ 2025년 12월 (반기별 현황 데이터 11개 종합)
* **최종 산출물:** `통합_따릉이_대여소_마스터.csv` (인코딩: `utf-8-sig`)
* **핵심 내용:** 서울시 전역의 따릉이 대여소 약 3,038여 곳의 고유 번호, 상세 위치(위/경도) 및 관할 자치구 정보

## 2. 전처리 목적 및 연구 가설 (공간 데이터 맵핑)
본 데이터셋은 개별적인 분석 목적보다는, **"PM(개인형 이동장치) 규제 효과 분석을 위한 월별 따릉이 이용정보"에 필수적인 공간 정보(자치구)를 부여하기 위한 '마스터 매핑(Mapping) 테이블' 역할**로 전처리되었습니다.

* **연구 맥락 및 활용:**
    * 따릉이 이용 기록 원본 데이터에는 각 대여소의 '고유 번호'만 존재할 뿐, 해당 대여소가 어느 지역(구)에 위치하는지 알 수 없습니다.
    * 자치구별로 상이한 PM 규제 강도와 인프라 수준을 따릉이 이용량과 교차 분석하려면 완벽한 공간 정보 맵핑이 필수적입니다.
    * 단일 마스터 정보의 한계(신설/폐쇄 대여소 누락)를 극복하기 위해, 2021년부터 최근까지 발표된 모든 반기별 대여소 현황 자료를 통합하여 결측치 0%에 도전하는 완성형 마스터 DB를 구축하였습니다.

## 3. 주요 전처리 로직 (Jupyter Notebook)
11개의 개별 파일(CSV, XLSX 혼재)에 흩어져 있는 대여소 정보를 일관된 형식으로 통합하고 최신화하였습니다.

* **데이터 로드 및 형식 일원화:** 다양한 인코딩(`cp949`, `utf-8`)과 확장자로 파편화된 데이터의 메타데이터(상단 5줄)를 무시하고 6개의 핵심 컬럼만을 일관되게 추출하였습니다.
* **식별자 정제 (Cleansing):** 소수점(`102.0`) 형태로 잘못 읽힌 대여소 번호를 순수 문자열(`'102'`)로 정제하고, 앞뒤 공백을 제거하여 완벽한 조인(Join) 키를 생성하였습니다.
* **중복 제거 및 최신화 (Deduplication):** 11개 데이터셋을 시간순으로 모두 이어 붙인(`concat`) 후, `대여소번호`를 기준으로 중복 행을 제거하되 가장 나중의 데이터(`keep='last'`)를 남겼습니다. 이를 통해 폐쇄된 대여소의 과거 기록은 보존하면서, 유지 중인 대여소의 위치 정보는 최신 상태로 갱신되도록 설계하였습니다.

## 4. 데이터 명세

| 컬럼명 | 설명 | 데이터 타입 | 비고 / 프로젝트 내 분석 활용 방안 |
| :--- | :--- | :--- | :--- |
| **대여소번호** | 공공자전거 대여소별 고유 식별 번호 | `string` | 타 데이터셋 조인 Key (Primary Key 역할) |
| **대여소명** | 정류장명, 랜드마크 등을 활용한 대여소 공식 명칭 | `string` | 식별 보조 지표 |
| **자치구** | 대여소가 위치한 서울시 내 자치구 명칭 | `string` | **PM 규제 정책 데이터와 결합하기 위한 공간 그룹화 Key** |
| **상세주소** | 대여소의 시/군/구 및 도로명 등 구체적 주소 | `string` | 인프라 밀집도 등 세부 분석 보조 지표 |

## 5. 활용 계획
* **데이터 병합 (Merge):** 완성된 마스터 DB를 월별 따릉이 이용 기록 원본과 `Left Join` 방식으로 병합하여 수백만 건의 대여/반납 데이터에 '자치구' 속성을 일괄 부여합니다.
* **시계열-공간 교차 분석:** 자치구별 PM 규제 도입 시점을 기준으로 그룹화하여 전후 따릉이 이용량 변화 추이를 통계적으로 분석합니다.
