# 서울시 공공자전거(따릉이) 월별 이용정보 데이터 전처리

## 1. 데이터 개요
* **데이터명:** 서울시 공공자전거(따릉이) 대여소별 이용정보 (월별 집계 통합본)
* **분석 기간:** 2018년 1월 ~ 2025년 12월 (8개년 장기 시계열 데이터)
* **최종 산출물:** `통합_따릉이_월별_이용정보.csv` (인코딩: `utf-8-sig`)
* **데이터 용량:** 원본 파일 61개(수백만 행)의 방대한 빅데이터를 분석 목적에 맞게 초압축 및 구조화

## 2. 전처리 목적 및 연구 가설 (대체 효과 검증)
본 데이터 전처리 파이프라인은 프로젝트의 핵심 연구 질문인 **개인형 이동장치(PM) 안전 규제 강화가 공공자전거(따릉이) 수요 대체 효과에 미친 영향**을 통계적으로 입증하기 위한 메인 종속 변수(Dependent Variable)를 정밀하게 산출하는 것을 목적으로 합니다.

* **연구 맥락 및 가설:**
    * 2021년 5월 강력한 PM(전동킥보드) 안전 규제(무단방치 견인 조치, 헬멧 착용 의무화 등)가 시행됨에 따라, 단거리 이동 수요가 이탈하여 대체재인 따릉이 이용량 증가로 이어졌을 것이라는 가설을 설정했습니다.
    * 이를 검증하기 위해 8년간의 방대한 대여 기록 데이터를 자치구별·월별 시계열 구조로 재구축하여, '전동킥보드 자치구별 견인 현황 데이터(규제 강도 지표)' 및 '코로나19 확진자 수 데이터(외생 통제 변수)'와 결합할 수 있는 결측치 없는 통합 패널 데이터셋을 구축하고자 합니다.

## 3. 주요 전처리 로직 (Jupyter Notebook)
수백만 건에 달하는 파편화된 대여 기록을 다변량 분석 및 패널 분석 모델에 즉각 투입할 수 있도록 효율적인 가공 및 정규화(Standardization)를 수행했습니다.

* **대용량 데이터 초압축 (Aggregation):** 성별, 연령대, 소모 칼로리 등 가설 검증과 무관한 변수들을 제거하고, 분석의 핵심 단위인 `[연월, 대여소번호]`를 기준으로 데이터셋을 그룹화(`groupby`)하여 전체 데이터 용량을 기하급수적으로 압축 및 경량화했습니다.
* **공간 데이터 매핑 (Spatial Join):** 8년 동안 신설 및 폐쇄된 대여소의 이력을 완벽히 반영하기 위해, 앞서 구축한 `통합_따릉이_대여소_마스터.csv` 테이블과 `대여소번호`를 Key로 삼아 `Left Join`을 수행했습니다. 이를 통해 개별 대여소가 속한 **'자치구'** 속성을 정확히 매핑하여 공간 분석의 정합성을 확보했습니다.
* **데이터 클렌징 및 표준화 (Cleansing & Standardization):** 과거(2018~2020년) 기록에 산발적으로 포함되어 있던 문자열 노이즈(작은따옴표 `'` 등)를 자동 식별하여 정제하고, 매년 제각각이었던 원본 컬럼명(`대여일자`, `대여년월` 등)과 날짜 포맷을 `YYYY-MM` 형태로 일관되게 통일했습니다.
* **결측치 안전 처리 (Safeguard):** 마스터 DB 등록 시점 차이 등으로 인해 자치구 매핑에 실패한 극소수(약 0.59%)의 임시/신규 대여소 데이터는 무조건 임의 삭제하는 대신 자치구명을 `미상`으로 처리했습니다. 이를 통해 서울시 전체 단위의 월별 따릉이 총수요(총량)가 과소평가되거나 왜곡되는 현상을 방지했습니다.

## 4. 데이터 명세

| 컬럼명 | 설명 | 데이터 타입 | 프로젝트 내 분석 활용 방안 |
| :--- | :--- | :--- | :--- |
| **연월** | 이용 통계가 집계된 연도와 월 (예: `2025-01`) | `string` | 타 데이터셋(PM 견인/코로나)과의 시계열 결합(Join) Key |
| **대여소번호** | 공공자전거 대여소별 고유 식별 번호 | `string` | 대여소 마스터 DB 결합 및 대여소별 거점 분석 Key |
| **이용건수** | 해당 연월, 특정 대여소에서 발생한 총 대여 건수 | `integer` | 규제 효과 및 수요 이동 분석의 **종속 변수 (Target)** |
| **이동거리** | 해당 대여소에서 출발한 자전거들의 총 이동거리 합계(M) | `float` | 규제 이후 이용 패턴 변화(단거리 이동성/레저 목적 등) 추정 보조 변수 |
| **이용시간** | 해당 대여소에서 출발한 자전거들의 총 이용시간 합계(분) | `integer` | 주행 특성 및 체류 시간 변화 파악을 위한 보조 변수 |
| **자치구** | 대여소가 위치한 서울시 25개 자치구 명칭 | `string` | **PM 견인 현황 데이터와 결합하여 자치구별 규제 효과를 비교하기 위한 공간 그룹화 Key** (매핑 실패 시 `미상`) |
