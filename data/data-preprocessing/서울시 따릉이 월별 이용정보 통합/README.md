# 서울시 공유 자전거(따릉이) 월별 이용정보 데이터 전처리 명세서 (README)

## 1. 데이터 개요
* **데이터명:** 서울시 공공자전거(따릉이) 대여소별 이용정보 (월별 통합본)
* **기간:** 2018년 1월 ~ 2025년 12월 (8년 치 시계열 데이터)
* **형태:** CSV (인코딩: `utf-8-sig`)
* **핵심 내용:** 서울시 25개 자치구에 위치한 약 3,000여 개의 따릉이 대여소별 월 단위 상세 이용 실적 (이용건수, 이동거리, 이용시간)

## 2. 전처리 목적 및 연구 가설 (대체 효과 검증)
본 데이터셋은 프로젝트의 핵심 연구 질문인 **"PM 안전 규제 강화 이후, 공유 자전거(따릉이)로의 이동 수단 대체 효과가 발생하였는가?"**를 통계적으로 입증하기 위한 메인 종속 변수로 활용하기 위해 전처리되었습니다.

* **연구 맥락 및 가설:**
    * 2021년 5월 강력한 PM(전동킥보드) 안전 규제(견인, 헬멧 의무화 등) 시행 이후, 규제 강도가 높은 지역일수록 PM 수요가 이탈하여 대체재인 '따릉이'의 이용량이 증가했을 것이라는 가설을 세웠습니다.
    * 8년간의 방대한 빅데이터를 자치구 단위로 통합하여, 전동킥보드 견인 현황 데이터(대리 지표) 및 코로나19 확진자 수 데이터(통제 변수)와 조인(Join)하여 규제 효과의 순수한 통계적 유의성을 검증합니다.

## 3. 주요 전처리 로직
원본 파일 수가 61개, 수백만 행에 달하는 초거대 용량 데이터를 다변량 분석 및 시계열 분석에 즉각 투입할 수 있도록 초압축 및 정규화(Standardization)를 수행하였습니다.

* **초압축(Aggregation) 및 구조화:** 방대한 개별 대여 기록에서 성별, 연령대, 소모 칼로리 등 불필요한 파생 변수를 버리고, 분석의 핵심인 `[연월, 대여소번호]` 기준으로 데이터를 그룹화(`groupby`)하여 전체 데이터의 크기를 기하급수적으로 압축 및 경량화하였습니다.
* **통합 마스터 DB 구축 및 공간 데이터 맵핑:** 8년 동안 신설/폐쇄된 모든 대여소의 위치 이력을 추적하여 직접 구축한 `통합_따릉이_대여소_마스터.csv`와 병합(Left Join) 하였습니다. 이를 통해 개별 대여소가 속한 **'자치구'** 파생 변수를 완벽히 매핑하여 공간 분석의 정합성을 확보하였습니다.
* **오류 데이터 클렌징 (Data Cleansing):** 2018년 등 과거 데이터에 혼재되어 있던 문자열 찌꺼기(작은따옴표 `'` 등)를 자동 식별하여 제거하고, 제각각이던 컬럼명(`대여일자`, `대여년월` 등)과 날짜 포맷(`YYYY-MM`)을 일관성 있게 표준화하였습니다.
* **결측치 안전 처리:** 마스터 DB에 등록되지 않아 자치구 매핑에 실패한 약 0.59%의 극소수 신규/임시 대여소 데이터는 삭제하지 않고 `미상`으로 처리하여, 서울시 전체 단위의 월별 따릉이 총 수요(총량)가 절대 왜곡되지 않도록 보존하였습니다.

## 4. 데이터 명세 (최종본)

| 컬럼명 | 설명 | 데이터 타입 | 비고 |
| :--- | :--- | :--- | :--- |
| **연월** | 이용 통계가 집계된 연-월 (예: `2025-01`) | `string` | 타 데이터셋 시계열 조인 Key |
| **대여소번호** | 공공자전거 대여소별 고유 식별 번호 | `string` | 마스터 DB 매핑 Key |

| **이동거리** | 해당 대여소에서 출발한 자전거들의 총 이동거리(M) | `float` | 이용 패턴(단거리/장거리) 추정 보조 지표 |

| **자치구** | 대여소가 위치한 서울시 25개 구 명칭 (매핑 실패 시 `미상`) | `string` | 타 데이터셋(견인/코로나) 공간 조인 Key |
