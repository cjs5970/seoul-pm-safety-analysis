# 서울시 자치구별 코로나19 확진자 수 데이터 전처리

## 1. 데이터 개요
* **데이터명:** 서울시 자치구별 코로나19 확진자 현황 (월별 통합본)
* **분석 기간:** 2020년 1월 ~ 2023년 8월 
* **최종 산출물:** `서울시_자치구별_월별_코로나19_확진자수.csv` (인코딩: `utf-8-sig`)
* **핵심 내용:** 서울시 25개 자치구 내 월 단위 코로나19 신규 확진자 수 집계 데이터 

## 2. 전처리 목적 및 분석 맥락 (통제 변수 구축)
본 데이터셋은 프로젝트의 핵심 연구 질문인 **"PM(전동킥보드) 안전 규제(단속 및 견인)가 대체재인 따릉이 이용량 증가에 미친 순수 인과 효과"**를 통계적으로 엄밀하게 검증하기 위해, **외부 환경 요인을 통제(Control)** 하는 목적으로 전처리되었습니다.

* **연구 맥락 및 활용 (가설 검증의 타당성 확보):**
    * 2020~2022년은 코로나19 팬데믹이 극심했던 시기로, 사회적 거리두기로 인한 대중교통 기피 현상이 발생하여 1인용 마이크로 모빌리티(따릉이, PM)의 거시적 수요가 전반적으로 폭증했습니다.
    * 따라서, 우리가 확인하고자 하는 '규제로 인한 따릉이로의 이동 수요 변화'가 단순히 코로나 확산세 증감에 따른 착시가 아님을 입증해야 합니다.
    * 이를 위해 자치구별·월별 확진자 수 패널 데이터를 구축하고, 추후 다변량 회귀 분석 모델링 시 주요 **통제 변수(Control Variable)**로 투입하여 전염병 요인에 의한 모빌리티 수요 변화를 분리 및 제거합니다.

## 3. 주요 전처리 로직 (Jupyter Notebook)
원본 엑셀 데이터의 복잡한 2중 다중 헤더(Multi-Index) 구조를 다차원 데이터 분석에 적합한 패널 형태(Tidy Data, Long Form)로 프로그래밍하여 변환하였습니다.

* **다중 헤더 정제 및 차원 축소:** `pandas`를 이용해 원본 데이터 로드 시 `header=[0, 1]`을 통해 멀티 인덱스로 읽어온 후, 분석에 불필요한 상위 그룹 컬럼('총합계', '기타', '타시도' 등)을 `drop` 처리하여 데이터의 복잡도를 낮추었습니다.
* **데이터 구조 변환 (Wide to Long):** `stack()` 메서드를 사용하여 가로(Wide)로 넓게 퍼져있던 25개 자치구 헤더를 세로(Long) 형태의 데이터 행으로 변환(Melt)함으로써, 추후 병합(Join)이 용이한 구조를 확립했습니다.
* **시계열 압축 및 그룹화 (Resampling & Aggregation):** 일자별로 기록된 약 3만 2천여 건의 시계열 날짜(`datetime`) 데이터를 `dt.to_period('M')`을 사용하여 월 단위(YYYY-MM)로 변환한 뒤, `[연월, 자치구]`를 기준으로 그룹화(`groupby().sum()`)하여 월간 총확진자 수 거시 지표로 완벽히 압축했습니다.
* **구조적 노이즈 및 결측치 제거:** 원본 엑셀 병합 셀로 인해 발생한 하단의 '총합계' 더미 행이나 타입 변환 오류를 발생시키는 쓰레기 값을 코드로 자동 필터링하여 결측치 0%의 완전한 데이터를 도출했습니다.

## 4. 데이터 명세 (최종본)

| 컬럼명 | 설명 | 데이터 타입 | 프로젝트 내 분석 활용 방안 |
| :--- | :--- | :--- | :--- |
| **연월** | 코로나19 확진자가 집계된 연-월 (예: `2023-08`) | `string` | 타 데이터셋(따릉이 이용량, 견인 건수) 시계열 결합 Key |
| **자치구** | 확진자가 발생한 서울시 25개 자치구 명칭 | `string` | 타 데이터셋 공간 결합(Join) Key |
| **월별_확진자수** | 해당 연월, 자치구 내 총 코로나19 확진자 수 | `integer` | 인과 추론 모델링 시 감염병 환경 변화를 통제하기 위한 **통제 변수 (Control Variable)** |

## 5. 활용 계획
* **다차원 패널 데이터 병합:** 정제 완료된 '따릉이 월별 이용 데이터' 및 '자치구별 PM 견인 현황 데이터'와 함께 `[연월, 자치구]`를 다중 결합 키(Multi-Key)로 설정하여 `Left Join` 병합을 수행, 통합 분석용 패널 데이터 프레임을 완성합니다.
* **인과 추론 및 회귀분석 모델 적용:** 이중차분법(DiD) 또는 다중 회귀분석(Multiple Regression) 실시 과정에서 독립 변수(규제 강도) 외에 이 코로나19 확진자 변수를 함께 투입합니다. 전염병 확산에 따른 따릉이 이용량 변화량을 통계적으로 통제함으로써, PM 규제 변수가 갖는 순수한 회귀 계수(효과 크기)를 추출하고 신뢰성 있는 최종 인사이트를 도출합니다.
