# 서울시 자치구별 코로나19 확진자 수 데이터 전처리 명세서 (README)

## 1. 데이터 개요
* **데이터명**: 서울시 자치구별 코로나19 확진자, 사망자 현황 (월별 집계본)
* **기간**: 2020년 1월 ~ 2023년 8월
* **형태**: CSV (인코딩: utf-8-sig)
* **핵심 내용**: 서울시 25개 자치구별 월 단위 코로나19 확진자 수 통계

## 2. 전처리 목적 및 연구 가설 (통제 변수 활용)
본 데이터셋은 PM(전동킥보드) 안전 규제가 이용량 및 사고율에 미친 순수한 정책 효과를 측정하기 위해, 외부 환경 요인을 통제(Control)하는 목적으로 전처리되었습니다.

* **연구 맥락 및 활용**
    * 코로나19 팬데믹 기간 동안 시민들의 대중교통 기피 현상으로 인해 PM 및 자전거 등 '1인용 마이크로 모빌리티' 수요가 전 세계적으로 폭증했습니다.
    * 따라서, 우리가 확인하고자 하는 'PM 규제 효과'와 '공유 자전거로의 대체 효과'가 단순히 코로나 확산세 증감에 따른 결과가 아님을 입증해야 합니다.
    * 추후 다변량 분석(회귀 분석 등) 모델링 시, 이 월별 확진자 수를 독립/통제 변수로 투입하여 모빌리티 수요의 거시적 흐름 변화를 설명할 예정입니다.

## 3. 주요 전처리 로직
원본 엑셀 데이터의 복잡한 다중 헤더(Multi-Index) 구조를 데이터 분석에 적합한 Tidy Data(Long Form) 형태로 변환하였습니다.

* **구조적 예외 처리**: 엑셀의 '병합된 셀'로 인해 발생한 컬럼 인식 오류 및 데이터 하단의 '총합계' 더미 행을 코드로 필터링하여 타입 변환 에러를 방지했습니다.
* **데이터 구조 변환 (Wide to Long)**: stack() 메서드를 사용하여 가로로 나열되어 있던 25개 자치구 헤더를 세로(행) 단위로 변환하여 시계열 분석 구조를 갖추었습니다.
* **시계열 합산 (Aggregation)**: 원본의 '일자별' 데이터를 타 데이터셋(견인 현황, 자전거 이용률)과의 병합(Join) 기준에 맞추기 위해 dt.to_period('M')을 사용하여 월 단위(YYYY-MM)로 합산(groupby-sum) 처리하였습니다.

## 4. 데이터 명세 (최종본)

| 컬럼명 | 설명 | 데이터 타입 | 비고 |
| :--- | :--- | :--- | :--- |
| 연월 | 코로나19 확진자가 집계된 연-월 (YYYY-MM)  | period  | 타 데이터셋 조인 Key  |
| 자치구 | 확진자가 발생한 서울시 자치구 명칭  | string  | 타 데이터셋 조인 Key  |
