# 서울시 전동킥보드 주차구역 현황 데이터 전처리 명세서 (README)

## 1. 데이터 개요
* **데이터명**: 서울시 전동킥보드 주차구역 현황 종합본 
* **형태**: CSV (인코딩: utf-8-sig)
* **핵심 내용**: 서울시 및 각 자치구 자체 예산으로 설치된 전동킥보드(PM) 주차구역 및 물리적 거치대 위치 정보 종합

## 2. 전처리 목적 및 연구 가설 
본 데이터셋은 PM 안전 규제 및 인프라 구축이 실제 시민의 안전(무단 방치 및 관련 사고 감소)에 미치는 긍정적 효과를 검증하기 위한 독립 변수(원인)로 활용하기 위해 전처리되었습니다.

* **주요 가설 검증**: "안전 제도 도입의 일환으로 PM 공식 주차구역을 많이 설치한 자치구일수록 무단 방치로 인한 교통사고(또는 보행자 사고) 증가율이 낮을 것이다."
* 즉, 인프라 확충 수준(주차구역 수)이 이전에 전처리한 '전동킥보드 견인 건수(대리 지표)'를 실제로 감소시켰는지 통계적으로 입증하는 데 사용됩니다.

## 3. 주요 전처리 로직 
분석의 정합성을 높이고, 자치구 단위의 다변량 분석 시타 데이터셋(견인/코로나)과의 조인이 용이하도록 아래와 같은 공정을 거쳤습니다.

* **형식 통일 및 데이터 추출**: 각 자치구별로 산재되어 제공되는 데이터의 포맷이 상이하여, 공통 필수 속성인 ['시군구명', '주소', '상세위치', '거치대유무']를 기준으로 데이터를 추출하고 형식을 일원화하였습니다.
* **데이터 병합 (Integration)**: 정제된 '각 지자체별 주차구역 데이터'와 '서울시 자체 예산 PM 주차 구역 데이터'를 하나로 병합(Concat/Merge)하여 누락 없는 서울시 전체 종합본을 구축하였습니다.
* **수동 보정 및 예외 처리 (Data Cleansing)**: 컬럼 형식이 크게 다르거나 자동화 병합 과정에서 누락된 예외 자치구(서대문구, 은평구 등)의 데이터는 수동으로 구조를 맞추어 반영함으로써 데이터의 완전성(Completeness)을 확보하였습니다.
* **인코딩 최적화**: 한글 깨짐 방지 및 타 분석 툴과의 호환성을 위해 utf-8-sig 포맷으로 최종 저장하였습니다.

| 컬럼명  | 설명  | 데이터 타입  | 비고  |
| :--- | :--- | :--- | :--- |
| 순번  | 고유 식별 번호 (Index)  | integer  | |
| 시군구명  | 주차구역이 위치한 서울시 자치구 명칭  | string  | 타 데이터셋 조인 및 그룹핑 Key  |
| 주소  | 주차구역의 도로명/지번 주소  | string  | 위치 기반 시각화(Folium 등) 활용 가능  |
