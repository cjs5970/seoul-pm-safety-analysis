# 서울시 공공데이터 원본 데이터셋

이 폴더는 `서울 열린데이터광장`에서 수집한 원본 데이터셋들을 관리합니다.

## 디렉터리 구성 및 설명

### 1. 서울시 공공자전거 따릉이 대여소 정보/
서울시의 공공자전거 따릉이의 대여소 정보(2021~2025)가 포함되어 있습니다.

### 2. 서울시 자치구별 코로나 확진자, 사망자 현황(일자별)_2020~2023(~8월)
서울시의 각 자치구별(`강남구, 종로구, ...`) 코로나 확진자, 사망자 현황(2020~2023-08)이 일자별로 포함되어 있습니다.

### 3. 서울시 전동킥보드 견인 현황_2022~2025
서울시 내 PM 정책 시행으로 인한 전동킥보드 견인 현황(2022~2025)이 포함되어 있습니다.

### 4. 서울시 전동킥보드 주차구역 현황
서울시에 운영되고 있는 전동킥보드 주차구역 현황이 각 자치구별 파일로 구분되어 포함되어 있습니다.

### 5. 서울시 전동킥보드 주차구역 현황
서울시의 월별 따릉이 이용정보(2018~2025)가 연도별로 구분된 폴더들이 포함되어 있습니다.
